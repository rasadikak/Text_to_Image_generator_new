# 🎨 Text-to-Image Generator Web App

A modern AI-powered web application that generates images from text prompts using advanced machine learning models. Users can enter descriptive text, and the system produces unique AI-generated images in seconds through API integration.

---

## 🚀 Features

- Generate images from text prompts
- AI-powered image creation
- Simple and user-friendly interface
- Real-time image generation
- Error handling for invalid prompts

---

## 🛠️ Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Flask

AI Integration:
- Hugging Face API

---

## ⚙️ Installation

1. Clone the repository:

git clone https://github.com/rasadikak/Text-to-image-generator_new.git  


2. Create virtual environment:

python -m venv env  

Activate environment (Windows):

env\Scripts\activate  

3. Install dependencies:

pip install -r requirements.txt  

4. Add your API key to `.env` file:

HF_TOKEN=your_huggingface_api_key  

5. Run the application:

uvicorn main:app --reload  

Open in browser:  
http://127.0.0.1:5000
